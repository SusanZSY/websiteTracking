## What we can track
This is a browser-side tracking demo, so we can track things like:

- page views
- button and link clicks
- source or referrer information
- redirect landing visits
- therapist booking clicks
- bookings by therapist
- clicks by source
- date-filtered activity in the dashboard
- time spent on the website
- mouse movement and hover heatmap behavior
- user session ID in the browser

## What we cannot track
This demo does not have a real backend or production analytics database, so we cannot reliably track:

- true customer identity across devices or browsers
- real backend conversion data from a live booking system
- secure personal or medical information
- complete sales funnel data beyond browser-side events
- exact attribution across multiple marketing platforms
- real-world conversion numbers from production systems
- cross-session user data without a backend database and consent setup

This project is useful for learning and demoing analytics behavior, but it is not a production-grade tracking system.
